# CodeGym Career - Material Design Landing Page

Bài thực hành xây dựng Landing Page theo phong cách Bootstrap Material Design.

## Thành phần
- `index.html`: cấu trúc Landing Page.
- `style.css`: CSS tùy chỉnh và responsive.
- `script.js`: xử lý menu mobile và form demo.

## Thư viện sử dụng
- Bootstrap 4.5.0
- MDBootstrap 4.19.1
- Font Awesome 5.11.2
- Google Fonts Roboto
- jQuery + Popper.js

## Các phần chính
1. Navbar responsive
2. Hero section + CTA
3. Tổng quan chương trình
4. 6 Material Cards về trải nghiệm học tập
5. Timeline lộ trình Bootcamp
6. Khóa học Java / PHP
7. Hỗ trợ nghề nghiệp
8. Form đăng ký tư vấn
9. Footer

## Cách chạy
Mở trực tiếp `index.html` bằng Chrome/Edge. Máy cần có Internet để tải Bootstrap/MDB/Font Awesome qua CDN.

## Responsive
Trang có breakpoint cho desktop, tablet và mobile.
